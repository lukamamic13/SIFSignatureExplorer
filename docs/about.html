About the project

Context, data sources, methods, and publication background for the SIF Signature Explorer

This page documents the data, processing choices, publication context, and reuse information behind the SIF Signature Explorer.

Paper

Publication

Mamić, L., Riches, M., Farmer, D. K., & Pirotti, F. (2025).

Solar-induced fluorescence as a robust proxy for vegetation productivity across climate zones and vegetation types in the United States.

Remote Sensing Applications: Society and Environment, 40 , 101760.

DOI: 10.1016/j.rsase.2025.101760

This explorer accompanies the publication and helps users interactively examine seasonal SIF signatures across vegetation types and climate zones.
What this adds

The paper presents a continental-scale assessment of seasonal SIF signatures across 33 vegetation types and 24 climate zones in the contiguous United States.

The web explorer turns this analysis into an interactive resource for comparing seasonal vegetation activity, climate-specific signatures, and SIF–GPP–NDVI relationships.

Overview

The SIF Signature Explorer visualizes seasonal solar-induced fluorescence signatures across vegetation types and climate zones in the contiguous United States. It accompanies the study by Mamić et al. (2025), which evaluates SIF as a proxy for vegetation productivity and compares its behaviour with GPP and NDVI.

Data sources

  • TROPOSIF/TROPOMI solar-induced fluorescence (SIF) retrievals at ~743 nm for 2019–2021 ( TROPOSIF project ).
  • USDA Cropland Data Layer land-cover classes, filtered for stable vegetation types and high classification confidence.
  • Köppen–Geiger climate classification used to assign each selected point to a climate category.
  • MODIS-derived normalized difference vegetation index (NDVI), leaf area index (LAI), fraction of absorbed photosynthetically active radiation (fPAR) and gross primary productivity (GPP) used as comparison variables.
  • Estimated stomatal conductance (Gs) derived as Gs ≈ GPP / √VPD, using GRIDMET vapor pressure deficit (VPD).

Computation of SIF signatures

  • Representative points were selected for each vegetation type–climate combination, prioritizing homogeneous pixels and limiting the number of points per combination.
  • Daily SIF and comparison variables were aggregated to weekly means for each selected point.
  • Weekly values were averaged across the 2019–2021 period to reduce the influence of anomalous years.
  • Locally Estimated Scatterplot Smoothing (LOESS) was applied separately to each vegetation type–climate combination to highlight the typical seasonal trajectory.
  • Mean values, standard deviation, and standard error are provided to describe seasonal variability.

Relationships between SIF, GPP and NDVI

The relationships page summarizes linear relationships between GPP–SIF, SIF–NDVI, and GPP–NDVI. These comparisons help show where SIF remains closely linked to productivity and where greenness-based indicators such as NDVI become less responsive to functional changes.

Code and data availability

The code and data used to generate this application, as well as materials illustrating the relationships between SIF, GPP and NDVI across vegetation types and climates, are available on GitHub: GitHub repository .

Usage notes

  • Results are intended for research, teaching, and exploratory interpretation.
  • Patterns should be interpreted with awareness of the spatial resolution of TROPOMI and the aggregation used to construct representative signatures.
  • Regression results are best interpreted as relative comparisons across vegetation and climate groups, not as absolute productivity estimates.
  • For full methodological details, please refer to the published article and repository.
